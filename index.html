Get Started

Install in
3 Simple Steps

01

Clone or Download

Get the source code directly from GitHub.

git clone https://github.com/Rohan-Shridhar/HopTab.git
02

Load as Extension

Open chrome://extensions and enable Developer Mode, then click “Load unpacked” and select the HopTab folder.

03

Start Using

Click the HopTab icon in your toolbar and start adding your favorite websites. That’s it — you’re ready to hop.
